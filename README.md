# Vipul - Easy Data Analytics Project

## Project Title
Sales Data Analysis Dashboard

## Objective
Analyze sales data to find:
- Total sales
- Best-selling product
- Top-performing city
- Monthly sales trend
- Average order value

## Tools
Python, Pandas, Matplotlib, Jupyter Notebook / VS Code

## How to run
1. Install Python.
2. Install packages:
   pip install pandas matplotlib
3. Run:
   python sales_analysis.py

## Resume line
"Analyzed sales data using Python and Pandas to identify top products, high-performing cities, and monthly sales trends."

## Interview points
- Cleaned and analyzed sales data using Pandas.
- Used groupby() for product/city analysis.
- Created charts using Matplotlib.
- Identified business insights from sales trends.
